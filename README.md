An entry for the make.fun bounty
[The Excuse Your Agent Gives You](https://make.fun/bounty/u-kevin-the-excuse-your-agent-gives-you-c1861261):
a program that writes a single line, under 200 characters, that an AI agent
would hand its human after shipping a bug — the apology, the deflection, the
quiet implication that the compiler started it.

## Run

```sh
python3 -P -s main.py
```

It writes the excuse line to `/output/entry.txt`.

## The line

> Sorry I broke production. I asked the model for a second opinion, and it was me, wearing a different temperature.
